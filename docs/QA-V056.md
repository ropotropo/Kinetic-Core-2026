# v0.5.6 — Compact mobile Guide portrait

Sole game author: Mykyta Borisov. 16 November 2026.

This focused presentation patch changes only the phone Guide hero CSS and
version/documentation/build metadata. Guide handlers, biography, lessons,
flight physics, checkpoint validation and desktop base styles are unchanged.

The phone portrait fills the viewport width without stretching. Cropping removes
upper sky; the face and KC suit patch stay visible. A lower black gradient leads
to a normal-flow row containing Play and About the author, clear of the subject.
Repeated introductory copy is hidden on phones. Desktop retains the approved
portrait-and-copy composition.
