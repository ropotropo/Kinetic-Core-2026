# SpaceX reference hardware — next-stage task

Requested by Andrii on 15 November 2026. Sole game author: Mykyta Borisov.
This is planned work; the current catalogue remains fictional training hardware.

Start with a Falcon 9 / Dragon reference vehicle, then evaluate a distinct
Starship / Super Heavy preset. The latter needs methane/oxygen performance,
Raptor engine layout, appropriate separation and independently tested booster
return. A new paint scheme or renamed fictional module is not a real model of
either vehicle. Keep the existing fictional sandbox presets available.

Use official version-dated specifications, distinguish published values from
unpublished mass/Isp assumptions, and retain source/license notices. Freeze the
reference revision before assigning performance numbers; do not silently update
the physical model when a real prototype changes. Never imply SpaceX endorsement.

Reference sources checked 15 November 2026:

- [SpaceX — Falcon 9](https://new.spacex.com/vehicles/falcon-9)
- [SpaceX — Starship](https://new.spacex.com/vehicles/starship)
- [SpaceX — Starship flight 12](https://www.spacex.com/launches/starship-flight-12/)

Acceptance: recognizable efficient geometry, documented performance assumptions,
correct wet/dry staging mass, finite fuel, per-engine thrust anchoring, validated
ascent/release and a clearly labelled reusable-booster scenario. Keep lunar crew
descent distinct from orbital Dragon operations. Orbital refuelling, tower catch
and return are additional mechanics, not capabilities of the current release.
