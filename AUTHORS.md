# Authorship and attribution

**Микита Борисов (Mykyta Borisov; GitHub: ropotropo), Ukraine, is the sole author of Kinetic Core, its original
game concept and creative direction.** Codex and specialist agents provide implementation,
design and verification assistance; they are tools, not additional game authors.

Use this authorship consistently in the game, package metadata, release notes
and a future repository transfer. The confirmed final name is **Kinetic Core**, with the Latin **KC** monogram.

Third-party work keeps its own attribution and license: Three.js and build
dependencies retain their notices; NASA/JPL/USGS imagery and physical reference
data retain their source credits. Those acknowledgments do not make their
creators authors of this game. Do not remove notices or imply NASA endorsement.
See [asset sources](public/assets/SOURCES.md) and the generated
`dist/THIRD_PARTY_NOTICES.txt`.

This authorship statement does not grant a new public license for the original
game code or assets. Mykyta can choose that license before external distribution
requires one. Existing third-party license terms continue to apply.

This repository starts a new snapshot history under Mykyta Borisov. The original repository history remains unchanged. A
repository-independent source export deliberately excludes `.git`; it carries
this authorship statement, credits and the complete committed project instead.
See [the transfer procedure](docs/REPOSITORY-TRANSFER.md).
